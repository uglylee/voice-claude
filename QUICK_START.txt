# 快速开始指南

## 仅需 3 步启动应用

### 步骤 1：安装依赖（一次性）

在命令行中运行：
```bash
pip install -r requirements.txt
```

### 步骤 2：立即运行

方案 A - Python 方式（推荐新手）：
```bash
python speech_recognition_app.py
```

方案 B - 生成 exe 文件（推荐分发）：
```bash
build.bat
```

然后双击生成的 `dist\语音识别.exe`

### 步骤 3：开始使用

1. 点击 "🎙️ 开始录音"
2. 对着麦克风说话
3. 点击 "⏹️ 停止录音"
4. 查看识别结果

---

## 遇到问题？

| 问题 | 解决方案 |
|------|--------|
| "无法找到 Python" | 重新安装 Python，勾选"Add to PATH" |
| "pip: 命令不存在" | 检查 Python 是否正确安装到 PATH |
| "没有麦克风" | 连接麦克风，检查系统设置 |
| "无法识别" | 离麦克风更近，减少噪音 |
